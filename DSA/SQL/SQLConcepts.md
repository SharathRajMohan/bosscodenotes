
## BASIC CONCEPTS

- SELECT, FROM, WHERE (filtering data)
- INSERT, UPDATE, DELETE (data manipulation)
- GROUP BY and AGGREGATE FUNCTIONS (COUNT, SUM, AVG, MIN, MAX)
- HAVING (filtering grouped data)
- ORDER BY and LIMIT (sorting and limiting the resultant rows)
- UNION vs UNION ALL (combining results)

## Intermediate/Advanced Topics:
- JOINs: Understand all types (INNER, LEFT, RIGHT, FULL OUTER, CROSS, SELF JOIN) and when to use them.
- Subqueries: Learn how to use nested queries.
- Common Table Expressions (CTEs): Use WITH clauses to break down complex logic and improve readability.
- Window Functions: Crucial for analytics roles. Be proficient with functions like RANK(), DENSE_RANK(), ROW_NUMBER(), LAG(), and LEAD().
- NULL Handling: Understand IS NULL, IS NOT NULL, and the COALESCE function.
